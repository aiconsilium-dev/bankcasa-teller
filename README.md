# 뱅크법률집사 — 행원 (여신·법무 담당)

## 데모
🔗 https://aiconsilium-dev.github.io/bankcasa-teller/

## 주요 기능
- **상황별 서류 작성** — 8개 상황(연체/가압류/추심/경매 등) → AI 분석 → 서류 자동 생성
- **서류 자동화 카탈로그** — 8종 서류 카드에서 바로 선택 → 정보 입력 → PDF 출력
- **채권계산기** — 원금·이자·지연손해금 자동 계산 (소촉법 §3① 연 12% 근거)
- **AI 법령·지침 검색** — 금융위/행안부 최신 고시·지침 검색
- **집변 법률상담** — 전담 변호사 즉시 연결

## 기술 스택
React + TypeScript + Vite + Tailwind CSS
